## 🎯 自动建表原理

### 启动流程

```
启动应用
  ↓
app.main.py @startup_event
  ↓
1. check_db_connection()  # 检查连接
  ↓
2. init_db()              # 初始化数据库
  ↓
  ├─ Base.metadata.create_all()  # 创建所有表
  ├─ 插入管理员用户（admin/admin123）
  └─ 插入8条预置术语
  ↓
启动成功 ✅
```

### 核心代码

**app/main.py**:
```python
@app.on_event("startup")
async def startup_event():
    check_db_connection()  # 检查连接
    init_db()              # 创建表 + 初始数据
```

**app/db/session.py**:
```python
def init_db():
    # 创建所有表
    Base.metadata.create_all(bind=engine)
    
    # 插入初始数据（检查是否已存在）
    # ...
```

## 🔗 与 SQL 脚本的对比

### SQL 脚本方式（手动）
```bash
mysql -u root -p < docs/sql/init_database.sql
```

### ORM 方式（自动）✅
```bash
python -m app.main  # 启动即创建
```

**推荐使用 ORM 方式**，因为：
- ✅ 自动化，启动即建表
- ✅ 与代码模型同步
- ✅ 支持 Alembic 迁移
- ✅ 更易维护
