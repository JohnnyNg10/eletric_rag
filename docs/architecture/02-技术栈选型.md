## 二、核心技术选型理由

### 1. FastAPI - 后端框架
**选型理由**：
- 原生支持异步，高并发性能优秀
- 自动生成OpenAPI文档
- Pydantic类型验证，开发效率高
- 与Python AI生态无缝集成

### 2. Qdrant - 向量数据库
**选型理由**：
- 原生支持稠密+稀疏向量混合检索
- Payload过滤功能强大（支持复杂条件）
- 单二进制部署简单，生产可扩展到分布式
- 内存优化好（Scalar Quantization）

### 3. React/Vue - 前端框架
**选型理由**：
- 组件化开发，易于维护
- 生态成熟，UI组件库丰富
- 支持SSR，首屏加载快
- 开发者社区活跃

### 4. Elasticsearch - 全文检索
**选型理由**：
- BM25算法精准匹配关键词
- 自定义分词器（电力术语）
- 运维工具完善
- 8.x版本支持原生向量检索（可选）

### 5. Airflow - 流程编排
**选型理由**：
- DAG可视化，流程清晰
- 失败重试、依赖管理
- 丰富的Operator扩展
- 适合复杂ETL任务
