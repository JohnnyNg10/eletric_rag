### ℹ️ 轻微问题

#### 4. 查询状态定义过于详细

**08文档定义了22个查询状态**，包括：
- PENDING, VALIDATING, AUTHENTICATING
- PREPROCESSING, NEED_CLARIFICATION
- CACHE_CHECKING, CACHE_HIT
- ROUTING, RECALLING, RERANKING
- SUFFICIENCY_CHECK, RETRY_RETRIEVAL
- REASONING, GENERATING
- EXTRACTING_CITATIONS, VALIDATING_FACTS
- CACHING, LOGGING
- SUCCESS, ERROR

**问题**: 状态过细可能导致：
- 状态转换逻辑复杂
- 性能开销（频繁更新状态）
- 难以维护

**建议**: 
- 合并相似状态（如 VALIDATING/AUTHENTICATING → VERIFYING）
- 区分核心状态和子状态
- 考虑使用状态组（如 PRE_PROCESSING, RETRIEVING, POST_PROCESSING）
