## 一、问题诊断

### 🔴 关键问题：代码与文档不一致

**文档要求**（design.md + 08-RAG功能层次与状态机.md）：
```
预处理层职责：
  ✅ 术语标准化
  ✅ 笼统度评估
  ❌ 查询改写（应该在快车道）
  ❌ 元数据提取（应该在快车道）

正确流程：
  术语标准化 → 笼统度评估 → 路由决策
    ↓
  快车道 → 查询改写 + 元数据提取 → 召回
  慢车道 → 直接推理
```

**当前代码实现**（`preprocessor.py` 第51-124行）：
```python
async def preprocess(self, input_data: PreprocessingInput):
    # 1. 术语标准化 ✅
    normalized_query = self.term_normalizer.normalize(query)
    
    # 2. 笼统度评估 ✅
    optimization_result = await self.query_optimizer.optimize(normalized_query)
    
    # 3. 查询改写 ❌ 应该在快车道
    expanded_queries = await self.query_rewriter.rewrite(normalized_query, ...)
    
    # 4. 元数据提取 ❌ 应该在快车道
    filters = self.metadata_extractor.extract(normalized_query)
```

**问题所在**：
- 当前 `Preprocessor` 包含了查询改写和元数据提取
- 这些操作应该在**路由决策后**，只在快车道执行
- 慢车道不需要查询改写和元数据提取

## 二、架构问题分析

### 问题1：职责边界不清晰

**当前架构**：
```
QueryService
  ↓
Preprocessor (包含所有预处理逻辑)
  ├─ TermNormalizer ✅
  ├─ QueryOptimizer ✅
  ├─ QueryRewriter ❌ 应该在 FastLane
  └─ MetadataExtractor ❌ 应该在 FastLane
```

**应该是**：
```
QueryService
  ↓
Preprocessor (仅核心预处理)
  ├─ TermNormalizer ✅
  └─ QueryOptimizer ✅
  ↓
Router (路由决策)
  ↓
FastLane (快车道)
  ├─ QueryRewriter ✅
  └─ MetadataExtractor ✅
  ↓
SlowLane (慢车道)
  └─ 工具调用循环
```

**新的 `Preprocessor`**（缩小职责）：
```python
class Preprocessor:
    """预处理协调器 - 仅负责术语标准化和笼统度评估"""
    
    def __init__(self):
        self.term_normalizer = TermNormalizer()
        self.query_optimizer = QueryOptimizer()
    
    async def preprocess(self, input_data: PreprocessingInput) -> PreprocessingOutput:
        """
        执行核心预处理流程
        
        流程：
        1. 术语标准化
        2. 笼统度评估
        """
        query = input_data.query.strip()
        
        # 步骤1: 术语标准化
        normalized_query = self.term_normalizer.normalize(query)
        
        # 步骤2: 笼统度评估
        if input_data.enable_optimization:
            optimization_result = await self.query_optimizer.optimize(normalized_query)
            
            if optimization_result.strategy in ['clarify_required', 'clarify_optional']:
                return PreprocessingOutput(
                    status='need_clarification',
                    optimized_query=normalized_query,
                    clarification_options=[...],
                    vagueness_score=optimization_result.vagueness_score
                )
        
        # 返回清晰查询
        return PreprocessingOutput(
            status='ready',
            optimized_query=normalized_query,
            vagueness_score=optimization_result.vagueness_score if optimization_result else 0.0
        )
```
