# 模型自动下载功能说明

## 功能概述

系统启动时会自动检查并下载所需的 AI 模型，包括：

1. **嵌入模型**：BAAI/bge-large-zh-v1.5（用于文本向量化）
2. **重排模型（大）**：BAAI/bge-reranker-large（精排）
3. **重排模型（小）**：BAAI/bge-reranker-base（粗排）
4. **稀疏向量模型**：naver/efficient-splade-VI-BT-large-query（关键词匹配）

## 配置说明

在 `.env` 文件中配置：

```bash
# 模型存储目录（相对于backend目录）
MODELS_DIR=models

# 模型名称（HuggingFace模型ID）
EMBEDDING_MODEL=BAAI/bge-large-zh-v1.5
RERANKER_MODEL_LARGE=BAAI/bge-reranker-large
RERANKER_MODEL_BASE=BAAI/bge-reranker-base
SPARSE_MODEL=naver/efficient-splade-VI-BT-large-query

# 是否自动下载缺失的模型
AUTO_DOWNLOAD_MODELS=True
```

## 使用方法

### 1. 自动下载（推荐）

启动应用时会自动检查和下载：

```bash
cd backend
python -m uvicorn app.main:app --reload
```

**国内网络环境**：如果需要访问 HuggingFace，设置代理：

```bash
# Windows
set HTTP_PROXY=http://127.0.0.1:7897
set HTTPS_PROXY=http://127.0.0.1:7897
python -m uvicorn app.main:app --reload

# Linux/Mac
export HTTP_PROXY=http://127.0.0.1:7897
export HTTPS_PROXY=http://127.0.0.1:7897
python -m uvicorn app.main:app --reload
```

### 2. 禁用自动下载

如果不希望自动下载，在 `.env` 中设置：

```bash
AUTO_DOWNLOAD_MODELS=False
```

然后手动下载模型到 `backend/models/` 目录。

### 3. 手动下载模型

使用 Python 脚本手动下载：

```python
from app.core.embedding.model_loader import get_download_manager

# 创建下载管理器
manager = get_download_manager("models")

# 下载单个模型
manager.download_model("BAAI/bge-large-zh-v1.5", proxy="http://127.0.0.1:7897")

# 批量下载
models = {
    "embedding": "BAAI/bge-large-zh-v1.5",
    "reranker_large": "BAAI/bge-reranker-large",
    "reranker_base": "BAAI/bge-reranker-base",
    "sparse": "naver/efficient-splade-VI-BT-large-query",
}
manager.download_all_models(models, proxy="http://127.0.0.1:7897")
```

## 常见问题

### 1. 下载速度慢

**原因**：国内访问 HuggingFace 速度慢。

**解决**：
- 设置代理：`export HTTP_PROXY=http://127.0.0.1:7897`
- 或使用 HuggingFace 镜像站（需修改代码）

### 2. 下载失败

**可能原因**：
- 网络连接问题
- 代理配置错误
- HuggingFace 服务异常

**解决**：
```bash
# 检查网络
curl -x http://127.0.0.1:7897 https://huggingface.co

# 手动下载模型
git clone https://huggingface.co/BAAI/bge-large-zh-v1.5 models/BAAI--bge-large-zh-v1.5
```

### 3. 磁盘空间不足

**模型大小**：
- bge-large-zh-v1.5: ~1.3GB
- bge-reranker-large: ~1.1GB
- bge-reranker-base: ~400MB
- efficient-splade: ~500MB
- **总计**: ~3.3GB

**解决**：清理磁盘空间或更改 `MODELS_DIR` 路径到更大的磁盘。

### 4. 启动时跳过模型检查

如果暂时不需要模型功能，可以：

```bash
AUTO_DOWNLOAD_MODELS=False
```

应用会记录警告但继续启动。相关功能将不可用。

## 开发说明

### 模型加载流程

1. **启动检查**：`app.main:startup_event()` 调用 `init_models()`
2. **检查存在性**：`ModelDownloadManager.check_model_exists()`
3. **自动下载**：`ModelDownloadManager.download_model()`（如果 `AUTO_DOWNLOAD_MODELS=True`）
4. **模型加载**：`ModelLoader.load_embedding_model()`（延迟加载，实际使用时）

### 核心模块

- `app/core/embedding/model_loader.py`：模型下载和加载
- `app/core/model_init.py`：启动时初始化
- `app/config.py`：模型配置

### 添加新模型

在 `app/config.py` 中添加配置：

```python
NEW_MODEL: str = "organization/model-name"
```

在 `app/core/model_init.py` 的 `init_models()` 中添加：

```python
models = {
    # ...
    "new_model": settings.NEW_MODEL,
}
```
