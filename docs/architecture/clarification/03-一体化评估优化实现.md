## 实现细节

### 1. 核心方法：`_llm_optimize()`

**一次 LLM 调用返回完整信息**：

```python
{
  "vagueness_score": 0.80,
  "missing_dimensions": ["电压等级", "应用场景"],
  "reason": "缺失维度说明",
  "options": [
    {
      "label": "10kV户内隔离开关技术参数",          # 给用户看的短标题（5-12字）
      "refined_query": "10kV户内隔离开关额定电流、额定电压及开断能力等技术参数要求"  # 送入检索的完整查询句（15-30字）
    },
    {
      "label": "35kV户外隔离开关安装要求",
      "refined_query": "35kV户外隔离开关安装间距、支撑绝缘子及操作机构技术要求"
    },
    {
      "label": "110kV隔离开关电气性能",
      "refined_query": "110kV隔离开关电气性能参数及机械寿命试验标准"
    }
  ]
}
```

### 2. 改进的 Prompt 设计

**旧方案**（2次调用）：
1. 调用1：评估笼统度 → 返回 `{"score": 0.8}`
2. 调用2：生成澄清选项 → 返回 3个选项

**新方案**（1次调用）：
- 在一个 Prompt 中同时要求评估和生成
- 返回包含评分、缺失维度、澄清选项的完整 JSON
- LLM 内部推理过程更连贯（评估时已理解缺失维度，直接生成对应选项）

### 3. 降级方案

LLM 失败时自动降级到规则方案：
- 规则评估笼统度
- 规则生成模板澄清选项
- 保证系统可用性

### 4. 向后兼容

保留了旧接口：
- `assess_vagueness()` - 单独评估笼统度
- `generate_clarification_options()` - 单独生成选项
- 内部会调用一体化方法，避免重复实现

## 使用示例

```python

optimizer = QueryOptimizer()

# 一体化优化（推荐）
result = await optimizer.optimize("隔离开关要求")

print(f"策略: {result.strategy}")  # clarify_required
print(f"笼统度: {result.vagueness_score}")  # 0.80

```
