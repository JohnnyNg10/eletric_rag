# 澄清功能与路由层集成使用指南

## 功能概述

本次实现完成了澄清功能与路由层的完整集成，用户可以通过选择澄清选项来优化查询，系统会自动记录澄清行为用于后续的 Loop Engineering 优化。

## 实现的功能

### 1. 完整的澄清流程

```
用户输入笼统查询
    ↓
术语标准化 + 笼统度评估
    ↓ (笼统)
返回澄清选项给前端
    ↓
用户选择澄清选项
    ↓
携带 refined_query 重新请求
    ↓
跳过笼统度评估，直接进入路由层
    ↓
路由 → 召回 → 生成答案
    ↓
记录 query_logs 和 clarification_logs
```

### 2. API 接口变更

#### POST /api/v1/query/

**请求体扩展** (QueryRequest):

```json
{
  "query": "隔离开关要求",          // 必填: 原始查询
  "stream": false,                   // 可选: 是否流式输出
  "conversation_id": null,           // 可选: 会话ID
  "filters": null,                   // 可选: 手动过滤条件
  
  // 澄清功能字段（用户选择澄清选项后提供）
  "refined_query": "10kV户内隔离开关技术参数",  // 可选: 精炼后的查询
  "selected_option_id": 1,                       // 可选: 选择的选项ID
  "clarification_context": {                      // 可选: 澄清上下文
    "vagueness_score": 0.75,
    "strategy": "clarify_optional",
    "options": [...],                              // 原始的澄清选项
    "missing_dimensions": ["电压等级", "应用场景"]
  }
}
```

**响应处理**:

1. **首次查询返回澄清选项** (HTTP 400):
```json

    "vagueness_score": 0.75,
    "options": [

        "label": "10kV户内隔离开关技术参数",
        "refined_query": "10kV户内隔离开关额定电流、额定电压等技术参数",
        "standard_preview": "GB 1985-2014",
        "doc_count": 23
      },
      {
        "id": 2,
        "label": "35kV户外隔离开关安装要求",
        "refined_query": "35kV户外隔离开关安装间距和技术要求",
        "standard_preview": "DL/T 593-2016",
        "doc_count": 18
      },
      {
        "id": 3,
        "label": "隔离开关操作与试验标准",

        "standard_preview": "GB/T 11022-2011",
        "doc_count": 15

```

2. **澄清后查询返回答案** (HTTP 200):
```json
{

```

## 前端集成示例

### Vue 3 Composition API

```typescript
import { ref } from 'vue'
import axios from 'axios'

interface ClarificationOption {
  id: number
  label: string
  refined_query: string
  standard_preview: string
  doc_count: number
}

interface ClarificationContext {
  vagueness_score: number
  strategy: string
  options: ClarificationOption[]
  missing_dimensions?: string[]
}

const query = ref('')
const needClarification = ref(false)
const clarificationOptions = ref<ClarificationOption[]>([])
const clarificationContext = ref<ClarificationContext | null>(null)
const answer = ref('')

// 首次查询
async function executeQuery() {
  try {
    const response = await axios.post('/api/v1/query/', {
      query: query.value,
      stream: false
    })
    
    // 直接返回答案（明确查询）
    answer.value = response.data.answer
    needClarification.value = false
    
  } catch (error) {
    if (error.response?.status === 400) {
      const detail = error.response.data.detail
      
      if (detail.error === '需要澄清查询') {
        // 触发澄清流程
        needClarification.value = true
        clarificationOptions.value = detail.options
        clarificationContext.value = {
          vagueness_score: detail.vagueness_score,
          strategy: detail.strategy,
          options: detail.options
        }
      }
    } else {
      console.error('查询失败:', error)
    }
  }
}

// 用户选择澄清选项后重新查询
async function selectClarificationOption(option: ClarificationOption) {
  try {
    const response = await axios.post('/api/v1/query/', {
      query: query.value,  // 原始查询
      refined_query: option.refined_query,  // 精炼查询
      selected_option_id: option.id,
      clarification_context: clarificationContext.value
    })
    
    // 返回答案
    answer.value = response.data.answer
    needClarification.value = false
    
  } catch (error) {
    console.error('澄清后查询失败:', error)
  }
}

// 用户跳过澄清，使用原始查询
async function skipClarification() {
  try {
    const response = await axios.post('/api/v1/query/', {
      query: query.value,
      refined_query: query.value,  // 使用原始查询
      selected_option_id: null,
      clarification_context: clarificationContext.value
    })
    
    answer.value = response.data.answer
    needClarification.value = false
    
  } catch (error) {
    console.error('查询失败:', error)
  }
}
```

### React Hooks

```typescript
import { useState } from 'react'
import axios from 'axios'

function useQuery() {
  const [query, setQuery] = useState('')
  const [needClarification, setNeedClarification] = useState(false)
  const [clarificationOptions, setClarificationOptions] = useState([])
  const [clarificationContext, setClarificationContext] = useState(null)
  const [answer, setAnswer] = useState('')

  const executeQuery = async () => {
    try {
      const response = await axios.post('/api/v1/query/', {
        query,
        stream: false
      })
      
      setAnswer(response.data.answer)
      setNeedClarification(false)
      
    } catch (error) {
      if (error.response?.status === 400) {
        const detail = error.response.data.detail
        
        if (detail.error === '需要澄清查询') {
          setNeedClarification(true)
          setClarificationOptions(detail.options)
          setClarificationContext({
            vagueness_score: detail.vagueness_score,
            strategy: detail.strategy,
            options: detail.options
          })
        }
      }
    }
  }

  const selectOption = async (option) => {
    try {
      const response = await axios.post('/api/v1/query/', {
        query,
        refined_query: option.refined_query,
        selected_option_id: option.id,
        clarification_context: clarificationContext
      })
      
      setAnswer(response.data.answer)
      setNeedClarification(false)
      
    } catch (error) {
      console.error('澄清后查询失败:', error)
    }
  }

  return {
    query,
    setQuery,
    needClarification,
    clarificationOptions,
    answer,
    executeQuery,
    selectOption
  }
}
```

## 数据库日志记录

### query_logs 表

记录每次查询的基本信息：

- `query`: 原始查询
- `normalized_query`: 标准化后的查询
- `lane`: 路由车道 (fast/slow)
- `vagueness_score`: 笼统度评分（首次查询）
- `clarified`: 是否触发澄清
- `retrieval_time`: 检索耗时
- `total_time`: 总耗时

### clarification_logs 表

记录澄清行为（仅当 `clarified=true` 时）：

- `query_log_id`: 关联的查询日志ID
- `original_query`: 原始笼统查询
- `refined_query`: 澄清后的查询
- `strategy`: 澄清策略
- `vagueness_score`: 笼统度评分
- `options_generated`: 生成的澄清选项（JSON）
- `user_choice`: 用户选择 (option_1/option_2/.../skip)
- `missing_dimensions`: 缺失的维度（JSON）

## Loop Engineering 支持

澄清日志为后续的 Loop Engineering 提供数据支持：

### 闭环1: Prompt 优化
- 统计高频笼统查询模式
- 分析误判案例（用户跳过率>80%）
- Few-shot 注入优质案例

### 闭环2: 术语库扩展
- 挖掘用户自定义输入中的新术语
- 分析缺失维度的高频关键词

### 闭环4: 测试集扩充
- 将用户选择的澄清选项加入测试集
- 防止效果退化

相关查询：

```sql
-- 统计澄清选项选择分布
SELECT user_choice, COUNT(*) as count
FROM clarification_logs
GROUP BY user_choice
ORDER BY count DESC;

-- 查找高跳过率查询（可能误判）
SELECT original_query, COUNT(*) as skip_count
FROM clarification_logs
WHERE user_choice = 'skip'
GROUP BY original_query
HAVING skip_count >= 3
ORDER BY skip_count DESC;

-- 查找高选择率查询（优质案例）
SELECT cl.original_query, cl.refined_query, cl.user_choice, COUNT(*) as select_count
FROM clarification_logs cl
WHERE cl.user_choice LIKE 'option_%'
GROUP BY cl.original_query, cl.refined_query, cl.user_choice
HAVING select_count >= 5
ORDER BY select_count DESC;
```
