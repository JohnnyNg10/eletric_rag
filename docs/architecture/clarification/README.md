## 功能概述

澄清功能负责在用户提交笼统查询时给出引导，完整流程为：

```
用户输入笼统查询
  ↓
术语标准化
  ↓
一体化评估和优化（一次 LLM 调用）
  ├── 笼统度 ≤ 0.5 → 直接进入路由层
  └── 笼统度 > 0.5 → 返回澄清选项给前端
                         ↓
                   用户选择澄清选项
                         ↓
               携带 refined_query 重新请求
                         ↓
            跳过笼统度评估，直接进入路由层
                         ↓
               记录 clarification_logs
```
