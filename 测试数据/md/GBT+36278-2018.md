# 电动汽车充换电设施接入配电网技术规范
## 1 范围
本标准规定了电动汽车充换电设施接入配电网的基本原则和技术要求。
本标准适用于接入110kV及以下电压等级电网的电动汽车充换电设施。

## 3 术语和定义
GB/T29317-2012和DL/T5729-2016界定的以及下列术语和定义适用于本文件。
### 3.1 接入点 access point of grid
电动汽车充换电设施接入电网的电气连接位置。
### 3.2 公共连接点 point of common coupling：PCC
电动汽车充换电设施接入公用电网的公共电气连接处。

## 4 总则
4.1 充换电设施接入电网所需线路走廊、地下电缆通道、变配电所站址等，应同步匹配城乡发展规划、土地利用规划、配电网中长期发展规划。
4.2 接入方案设计前需校核接入点供电容量，在满足电网安全稳定运行前提下，保障充换电设施可靠供电。
4.3 充换电设施配电、通信、测控配置应适配配网自动化系统，接入运行后不得降低原有配网供电可靠性。
4.4 充换电设施宜按远期饱和总容量统一规划、一次土建，充电机、变电器等电气设备可分期分批安装投运。

## 5 接入电网原则
### 5.1 电压等级
5.1.1 充换电系统标称电压需符合GB/T 156标准电压系列要求。
5.1.2 供电电压等级根据充换电总容量、需用系数、负荷同时系数经技术经济比选确定，适用容量区间50kVA～20MVA。
表1 充换电设施推荐供电电压等级
| 总容量区间 | 推荐接入电压等级 |
| ---- | ---- |
| 单台/小容量充电机 | 220V / 380V |
| 50kVA～4000kVA | 10kV |
| 4000kVA～8000kVA | 20kV |
| 8MVA～20MVA | 35kV / 110kV |

5.1.3 负荷计算需结合单台充电额定功率、设备日均使用频次、站内同时投运台数合理选取同时系数，避免负荷计算偏大或偏小。

### 5.2 用户等级
5.2.1 用户分级标准执行GB/Z 29328重要电力用户规范。
5.2.2 具备重大交通保障、政务保障功能，停电将造成公共交通大面积瘫痪、重点单位停运的充换电站划分为二级重要电力用户；其余普通充换电站、分散充电桩为一般用户。

### 5.3 接入点选型
5.3.1 220V单相充电桩：优先接入小区/园区公用低压配电箱；380V三相充电机采用专用低压分支线路接入配电室。
5.3.2 10(20kV)接入：容量≤4000(8000)kVA可T接10kV公用架空/电缆线路、环网柜、电缆分支箱；容量＞4000(8000)kVA宜采用10kV专线单独接入变电站母线。
5.3.3 35kV、110kV充换电站：可T接公用输电线路，或直接接入对应电压等级变电站母线。
5.3.4 各电压等级典型接入拓扑见附录A示意图。

### 5.4 供电距离
需根据充换电负荷大小、系统常态运行电压水平做电压降计算，控制公共连接点、充换电接入点电压偏差满足GB/T12325限值，以此确定最大合理供电半径。

### 5.5 接线形式
5.5.1 35kV、110kV高压侧主接线执行GB50059；二级重要用户高压侧宜采用桥形、单母线分段、线路变压器组方案，至少两台主变；低压侧采用单母线分段接线。
5.5.2 10kV及以下站内接线执行GB50053；二级重要用户10kV进线宜单母线分段。
5.5.3 配电变压器低压侧预留1～2回备用出线回路，满足后期扩容增桩需求。

### 5.6 供电电源配置
5.6.1 电源接入点短路容量、供电裕量需满足充换电最大负荷，保证电能质量合格、电网故障时不扩大事故。
5.6.2 二级重要充换电站：采用双独立电源供电；任一电源故障，另一路可带全部保安负荷；配套自备应急电源，容量覆盖全站保安负荷。
5.6.3 一般充换电站：可单回路供电；宜配置应急电源，容量不低于80%保安负荷。

### 5.7 接地匹配
充换电站站内接地网、变压器中性点接地方式必须与上级配电网接地制式保持一致。

## 6 设备选择
### 6.1 一般要求
配电变压器、接入线路、开关柜等设备选型满足GB 50054低压配电规范。

### 6.2 供电变压器
6.2.1 常规场景优先选用干式低损耗节能配电变；重载、户外、大容量场景可选用油浸式变压器。
6.2.2 220V单相充电桩配套变压器宜采用Dyn11接线组别，抑制三相不平衡与三次谐波。

### 6.3 接入线路
6.3.1 导线截面按远期饱和容量一次性选定，预留扩容裕度。
6.3.2 截面选型以经济电流密度为基础，校验长期载流量、机械强度。

### 6.4 电缆敷设
电缆敷设执行GB 50217；电力电缆禁止与热力管、易燃易爆燃气/液体管道同沟敷设。

## 7 无功补偿
7.1 无功补偿装置与充换电站主体同步规划、同步施工、同步投运。
7.2 补偿装置就地布置，可分档自动投切，便于实时调压。
7.3 功率因数限值：10kV及以上站点高峰负荷功率因数不宜低于0.95；380V/220V低压站点不宜低于0.9，不达标需增设动态无功补偿装置。
7.4 补偿装置可根据站内充电机投切状态自动分组投切，跟踪负荷无功变化。

## 8 保护和计量
### 8.1 继电保护
8.1.1 220V/380V低压充换电：低压断路器、过载短路保护配置执行GB50054。
8.1.2 10kV～110kV充换电站：站内及线路保护配置、整定符合GB/T14285继电保护规程。

### 8.2 电能计量
8.2.1 计量点原则设置在电网与充换电设施产权分界处。
8.2.2 计量装置配置、精度、管理执行DL/T448。
表2 充换电设施计量装置分级标准
| 设施类型/容量 | 月平均用电量 | 计量装置类别 |
| ---- | ---- | ---- |
| 单相220V充电桩 | 不限 | V类 |
| 容量＜315kVA三相站点 | 不限 | IV类 |
| 315kVA≤容量＜2000kVA | ≥10万kWh | III类 |
| 2000kVA及以上 | ≥100万kWh | II类 |
| 10000kVA及以上大型充换电站 | ≥500万kWh | I类 |

## 9 电能质量
9.1 谐波：公共连接点谐波电压、谐波电流限值执行GB/T14549。
9.2 电压偏差：公共连接点稳态电压偏差满足GB/T12325。
9.3 三相不平衡：公共连接点三相电压不平衡度符合GB/T15543。

# 附录A（资料性附录）充换电设施接入电网示意图
## A.1 220V/380V低压接入（图A.1）
### 图纸技术文字解释
拓扑层级：公网220/380V低压配电箱母线→断路器/负荷开关（接入点）→分支线路→单台/多台充电设备。
适用场景：小区分散交流桩、小型户充、街边低压充电桩；接入点设置在配电分支开关处，便于单台充电桩故障隔离，不影响同母线其他负荷。

## A.2 10kV单回路接入（图A.2）
### a）T接10kV公用架空/电缆线路
技术拓扑：变电站10kV出线母线→公用10kV主干线路→T接点（接入点，装设断路器）→站内10kV配电母线→变压器→充电设备。
适用容量≤4000kVA中小型充电站；T接处配置保护开关，站内故障不扩散至主干线。
### b）接入10kV环网柜/电缆分支箱
技术拓扑：变电站10kV线路→环网柜（接入点）→出线开关→充电站配电系统；适合城区电缆网密集区域，利用现有环网资源，无需新建长专线。
### c）10kV专线接入
技术拓扑：变电站10kV母线单独出线（专线，接入点为站内10kV进线柜），全程专用电缆/架空至充换电站，无其他负荷共享线路；适合容量4000kVA～8000kVA大型充电站，供电可靠性更高，故障影响范围小。

## A.3 10kV双回路接入（图A.3）
### 图纸技术文字解释
两路独立10kV电源（电源A、电源B，取自不同变电站母线或同站不同母线段）分别通过环网/线路接入站内双10kV母线，两路进线均设置断路器接入点；站内可配置备自投装置。
适用二级重要充换电站，单路电源停电时另一路可带全部保安负荷，满足不间断充电保障需求。

## A.4 35kV/110kV单回路接入（图A.4）
### a）专线接入变电站母线
公网35/110kV变电站母线单独出线专线至充换电站高压配电装置，接入点为站内高压进线开关；适合8MVA以上大型集中充换电枢纽。
### b）T接35kV/110kV公用输电线路
主干高压线路T接分支至充换电站，接入点设置隔离开关+断路器；适用于郊区、公路沿线大中型充换电站，可减少新建变电站投资。

## A.5 35kV/110kV双回路接入（图A.5）
### 图纸技术文字解释
两路独立35kV或110kV电源，分别来自不同供电分区变电站，双高压母线供电，两路进线为独立接入点；配置高压备自投，属于一级/二级重要负荷标准接入方案，完全避免单条线路检修、全线停电导致全站停运。
